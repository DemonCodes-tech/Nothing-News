## What Is Nothing News?

Nothing News is a personal news app built for clean reading, quick scanning, and deeper context without clutter.

It brings together:

- A curated, readable news feed
- Topic-based reading and personal collections
- Offline-friendly article saving and revisit flows
- A polished Nothing-inspired interface
- Tools to compare coverage, track trends, and revisit updates later

---

## Features

### Reading
- Clean article cards and focused browsing
- Fast headline summaries and deeper reading modes
- Timeline-style reading for ongoing stories
- Personal article saves and collections

### Personal Tracking
- Reading history and saved articles
- Category and topic organization
- Follow-up summaries for important developments
- Lightweight context and trend views

### Design
- Nothing OS 5.0 inspired UI
- Frosted glass, adaptive colors, and motion-driven interactions
- Dark mode and calm, distraction-free layout

### Infrastructure
- Offline-friendly article access
- Local storage and sync-friendly architecture
- Flexible, app-level personalization

## Quick Start

### Prerequisites
- Android Studio
- JDK 17+
- Android SDK 36

### Run locally
1. Clone the repository.
2. Open the project in Android Studio.
3. Let Gradle sync.
4. Run the app on an emulator or connected device.
